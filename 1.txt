按现有方案：**Ubuntu 22.04 宿主机安装 NVIDIA 驱动、Docker 和 NVIDIA Container Toolkit；ROS1、Gazebo、GO2 策略继续使用原来的容器镜像。** 安装方式依据 [Ubuntu 驱动文档](https://documentation.ubuntu.com/server/how-to/graphics/install-nvidia-drivers/)、[Docker 官方文档](https://docs.docker.com/engine/install/ubuntu/)和 [NVIDIA 容器文档](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html)。

**1．新电脑：安装基础工具和显卡驱动。**

```bash
sudo apt update

sudo apt install -y \
  ubuntu-drivers-common linux-headers-$(uname -r) \
  ca-certificates curl gnupg git rsync \
  openssh-client openssh-server \
  build-essential cmake pkg-config \
  python3 python3-pip python3-venv \
  mesa-utils x11-xserver-utils xauth \
  sysstat htop tmux unzip gzip

sudo systemctl enable --now ssh

ubuntu-drivers list
sudo ubuntu-drivers install
```

**2．新电脑：安装 Docker。**

```bash
sudo install -m 0755 -d /etc/apt/keyrings

sudo curl -fsSL \
  https://download.docker.com/linux/ubuntu/gpg \
  -o /etc/apt/keyrings/docker.asc

sudo chmod a+r /etc/apt/keyrings/docker.asc

sudo tee /etc/apt/sources.list.d/docker.sources >/dev/null <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: jammy
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update

sudo apt install -y \
  docker-ce docker-ce-cli containerd.io \
  docker-buildx-plugin docker-compose-plugin

sudo systemctl enable --now docker
sudo usermod -aG docker "$USER"
```

**3．新电脑：安装 GPU 容器运行时、分析工具，然后重启。**

```bash
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey |
  sudo gpg --dearmor --yes \
    -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg

curl -fsSL \
  https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list |
  sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' |
  sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list >/dev/null

sudo apt update
sudo apt install -y nvidia-container-toolkit

sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker

python3 -m venv "$HOME/.venvs/lrae-tools"

"$HOME/.venvs/lrae-tools/bin/python" -m pip install --upgrade pip

"$HOME/.venvs/lrae-tools/bin/python" -m pip install \
  numpy scipy matplotlib PyYAML psutil rosbags pillow

sudo reboot
```

重启后，在**新电脑的图形桌面终端**执行：

```bash
nvidia-smi
glxinfo -B
docker version

source "$HOME/.venvs/lrae-tools/bin/activate"
```

**4．旧电脑：导出现有 ROS1 镜像。这个镜像是本地构建的，不能直接通过 `docker pull` 获取。**

```bash
sudo apt install -y openssh-server rsync
sudo systemctl enable --now ssh

docker image inspect gbplanner_ros1_go2:gpu >/dev/null

docker save gbplanner_ros1_go2:gpu |
  gzip -1 > "$HOME/gbplanner_ros1_go2_gpu.tar.gz"

hostname -I
```

**5．新电脑：输入旧电脑的 SSH 地址，迁移镜像、工作区和场景。**

**6．新电脑：检查容器，重新编译并启动已验证的 V7 基准。**

```bash
source "$HOME/.venvs/lrae-tools/bin/activate"

export SIM_UNDERLAY="$HOME/lrae_underlay/ws"
export WORLD_DIR="$HOME/World/njupt_gazebo_optimized"
export IMAGE="gbplanner_ros1_go2:gpu"
export LRAE_PROJECT="$HOME/lrae_experiments"

docker run --rm --gpus all "$IMAGE" nvidia-smi

docker run --rm "$IMAGE" bash -lc \
  'source /opt/ros/noetic/setup.bash; rosversion -d; gazebo --version'

test -f \
  "$SIM_UNDERLAY/devel/.private/catkin_tools_prebuild/setup.bash"

test -d "$WORLD_DIR/models/njupt_xianlin_optimized"

ACTION=build \
  bash "$LRAE_PROJECT/outputs/reverse-v7-20261110/run_sim.sh"
```
