按下面顺序准备即可。

1. **安装 Git 和 Python 虚拟环境。** Ubuntu 22.04 自带的 Python 3.10 可以用于包内固定版本。

   ```bash
   sudo apt update
   sudo apt install -y git unzip python3 python3-venv python3-pip
   nvidia-smi
   ```

   本方案建议驱动为 `560.35.05` 或更新，以覆盖 CUDA 12.6 运行库；如果已经更新，就保留当前驱动。[NVIDIA 版本说明](https://docs.nvidia.com/cuda/archive/12.6.3/cuda-toolkit-release-notes/)

2. **解压迁移包，恢复代码并应用补丁。** 在解压后的 `Electronic-2080Ti-4B` 文件夹中执行：

   ```bash
   git clone -b feature/unified-drawing-review-20261106 ./Electronic.bundle ./Electronic
   cd Electronic
   git apply ../2080ti-4b.patch
   ```

   原代码写死了 BF16，补丁将其改为适合 2080 Ti 的 FP16，并把默认模型改为 4B。

3. **创建环境，安装 CUDA 版 PyTorch 和项目依赖。**

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install --upgrade pip
   python -m pip install torch==2.14.0 torchvision==0.29.0 \
     --index-url https://download.pytorch.org/whl/cu126
   python -m pip install -r ../requirements-ubuntu.txt
   python -m pip check
   ```

   依赖包括 Transformers、Accelerate、bitsandbytes、PyMuPDF、Pillow、OpenCV 和 openpyxl。这个 PyTorch／torchvision 组合来自[官方安装说明](https://pytorch.org/get-started/previous-versions/)。**不要运行 `uv sync` 或 `pip install -e .`，仓库的 `pyproject.toml` 仍面向 macOS／MLX。**

4. **下载多模态 4B 模型，再做小规模测试。**

   ```bash
   hf download Qwen/Qwen3.5-4B

   python scripts/drawing_pipeline.py /你的路径/图纸.pdf \
     --output ./runs/4b-smoke-01 \
     --model-id Qwen/Qwen3.5-4B \
     --max-calls 5 --serve
   ```

   下载的是[官方多模态模型](https://huggingface.co/Qwen/Qwen3.5-4B)，程序加载时再进行 NF4 量化。打开终端给出的本地复核地址；确认没有显存或模型调用错误后，换一个输出目录，去掉 `--max-calls 5` 跑完整图纸。

这条流程使用预编译包，**暂时无需另装系统 CUDA Toolkit、cuDNN、Docker、Ollama 或 vLLM，也先别装 `flash-attn`**。Tesseract 中文 OCR 只在继续使用旧 Fast 的独立 OCR 功能时需要。

迁移补丁已通过 **22 项离线测试**；还没有在 2080 Ti 上运行 4B。完整命令和检查方法也可单独查看[安装说明](/home/t1an/Documents/Codex/2026-11-10/electronic-codex-threads-01a1aef7-f412-7fc0/outputs/Electronic-2080Ti-4B-安装说明.txt)。模型权重、工程 PDF 和旧复核结果需要另外下载或复制。
